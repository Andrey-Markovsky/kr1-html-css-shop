# Учебный frontend-проект «ShopProject»

## Описание
Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема проекта: многостраничный сайт интернет-магазина цифровых комплектов, UI-китов и обучающих материалов для веб-разработчиков.

## Структура проекта
- `index.html` — главная страница (hero-блок, преимущества, витрина популярных товаров с переходом на карточку каждого товара и быстрым заказом, блок FAQ, модальное окно заявки);
- `catalog.html` — расширенный каталог из 6 цифровых товаров с тематическими иллюстрациями, фильтрами и CSS Grid-сеткой;
- `product.html` — динамическая страница товара (`product.html?id=1..6`) с двухколоночной раскладкой, интерактивной мини-галереей, переключателем всех 6 товаров и таблицей сравнения комплектаций;
- `order.html` — отдельная страница оформления заказа и заявки;
- `contacts.html` — контактная информация и переход к обратной связи;
- `css/style.css` — единый файл стилей (CSS-переменные в `:root`, Flexbox, CSS Grid, методология БЭМ, интерактивные состояния и адаптивность);
- `js/main.js` — скрипт открытия/закрытия модального окна и клиентской валидации формы;
- `images/` — директория для графических материалов проекта;
- `README.md` — документация проекта;
- `.gitignore` — список служебных файлов, исключённых из Git.

## Ассортимент магазина (доступны индивидуальные карточки всех 6 товаров)
При нажатии кнопки «Подробнее» на главной странице или в каталоге открывается персональная страница конкретного товара:
1. `product.html?id=1` — **Стартовый шаблон «ShopStarter UI»** (Арт. `SP-01`);
2. `product.html?id=2` — **Дизайн-система «RootTokens CSS»** (Арт. `SP-02`);
3. `product.html?id=3` — **Пакет форм «SmartForms & Dialog»** (Арт. `SP-03`);
4. `product.html?id=4` — **Практикум «Мастер сеток: Grid & Flex»** (Арт. `SP-04`);
5. `product.html?id=5` — **Руководство «БЭМ и доступность (a11y)»** (Арт. `SP-05`);
6. `product.html?id=6` — **Полный бандл «Frontend-разработчик»** (Арт. `SP-06`).

## Используемые технологии
- **HTML5** (семантическая разметка, веб-формы, таблицы, `<dialog>`, `<details>`/`<summary>`, оптимизированные изображения `<img>` с `alt`, `width`, `height`, `loading="lazy"`);
- **CSS3** (дизайн-токены в `:root`, Flexbox, CSS Grid, `object-fit: cover`, позиционирование `relative`/`absolute`/`sticky`/`fixed`, медиазапросы `@media`);
- **Методология БЭМ** (Блок, Элемент, Модификатор);
- **JavaScript** (динамическая подгрузка описания, цен, фото и характеристик выбранного товара по URL-параметру `?id=`, переключение превью в галерее, управление модальным окном `<dialog>` и валидация формы);
- **Git и GitHub** (контроль версий, публикация через GitHub Pages).

## Контрольная работа №2
Тема: «HTML и CSS: разработка многостраничного сайта».
В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина со сквозной навигацией, иллюстрированными карточками 6 товаров, динамической детальной страницей для каждого продукта, таблицей сравнения тарифов, формами заявки и модальным окном.

## Самостоятельные доработки
1. **Индивидуальные страницы для всех 6 товаров (`product.html?id=1..6`)** — при нажатии на кнопку «Подробнее» в каталоге или на главной странице пользователь переходит на страницу с индивидуальным названием, фото, описанием, составом комплекта, ценой и таблицей характеристик выбранного товара. Также добавлена панель быстрого переключения между всеми 6 товарами (`.product-switcher`).
2. **Конкретные наименования и тематические изображения товаров** — все карточки наполнены реальными названиями цифровых продуктов и иллюстрациями с фиксированными пропорциями (`object-fit: cover`).
3. **Детальная двухколоночная карточка товара (`product-card--detailed`)** — содержит интерактивную мини-галерею (при клике на превью меняется главное фото), теги технологий, панель спецификаций и выбор редакции (Base / Pro).
4. **Расширенная таблица характеристик и сравнения тарифов (`product.html`)** — семантическая таблица `.product-table`, сравнивающая базовую и расширенную версии выбранного товара по 8 параметрам.
5. **Блок часто задаваемых вопросов (`index.html`)** — интерактивный БЭМ-блок `.faq` на базе тегов `<details>` и `<summary>`.
6. **Улучшенное модальное окно и доступность формы (`index.html`)** — шапка `.order-dialog__header`, индикаторы обязательных полей (`*`), `aria-describedby`, `aria-required="true"`, `aria-invalid="true"`.
7. **Фиксированная кнопка «Наверх» (`.back-to-top`)** — быстрый возврат к началу страницы (`position: fixed`).

## Как проверить проект
1. Открыть опубликованную версию на GitHub Pages: https://Andrey-Markovsky.github.io/kr1-html-css-shop/
2. На главной странице в блоке «Популярные товары» или на странице «Каталог» нажать кнопку «Подробнее» на любом товаре — откроется страница `product.html` с данными именно этого товара.
3. На странице «Товар» проверить переключение между всеми 6 товарами через верхнюю панель быстрого перехода, кликнуть по миниатюрам в галерее и проверить таблицу характеристик.
4. Проверить открытие модального окна по кнопке «Заказать» и валидацию формы заявки.
