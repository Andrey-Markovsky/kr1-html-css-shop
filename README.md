# Учебный frontend-проект

## Описание
Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта
- `index.html` — главная страница (hero-блок, преимущества, популярные товары, блок FAQ, модальное окно заявки);
- `catalog.html` — расширенный каталог товаров с фильтрами и Grid-сеткой;
- `product.html` — подробная карточка товара и расширенная таблица характеристик;
- `order.html` — отдельная страница оформления заказа и заявки;
- `contacts.html` — контактная информация и переход к обратной связи;
- `css/style.css` — единый файл стилей (CSS-переменные, Flexbox, Grid, БЭМ, состояния);
- `js/main.js` — скрипт открытия/закрытия модального окна и базовой валидации формы;
- `images/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Используемые технологии
- HTML5 (семантическая разметка, формы, таблицы, `<dialog>`, `<details>`/`<summary>`);
- CSS3 (переменные `:root`, Flexbox, CSS Grid, позиционирование `relative`/`absolute`/`sticky`/`fixed`);
- Методология БЭМ (Блок, Элемент, Модификатор);
- JavaScript (управление модальным окном, клиентская проверка валидности);
- Git и GitHub (работа с ветками, Pull Request, публикация через GitHub Pages).

## Самостоятельные доработки 
В рамках самостоятельного развития проекта реализованы следующие улучшения:
1. **Расширенный каталог товаров (`catalog.html`)** — сетка увеличена до 6 карточек товаров с категориями, артикулами и абсолютно позиционированными бейджами (`position: absolute` внутри `position: relative`: «Хит», «Скидка», «Новинка», «Топ»).
2. **Более подробная карточка товара (`product-card`)** — в карточки добавлены метаданные (`.product-card__meta`), индикатор наличия (`.product-card__status`), список ключевых характеристик (`.product-card__features`) и старая перечёркнутая цена для товаров со скидкой (`.product-card__old-price`).
3. **Расширенная таблица характеристик и сравнения тарифов (`product.html`)** — создана семантическая таблица `.product-table` (`caption`, `thead`, `tbody`, `th`, `td`), сравнивающая базовую и Pro-комплектации по 8 параметрам.
4. **Блок часто задаваемых вопросов (`index.html`)** — разработан интерактивный БЭМ-блок `.faq` на базе раскрывающихся семантических тегов `<details>` и `<summary>`.
5. **Улучшенное модальное окно (`index.html`)** — в блок `.order-dialog` добавлена выделенная шапка `.order-dialog__header` с заголовком, поясняющим подзаголовком `.order-dialog__subtitle` и разделительной линией.
6. **Фиксированная кнопка «Наверх» (`.back-to-top`)** — на всех страницах добавлена кнопка быстрого возврата к началу страницы с `position: fixed` и `z-index: 90`.
7. **Дополнительные состояния кнопок и карточек** — реализованы плавные переходы `transition`, состояние нажатия `:active` для кнопок, подъём карточек с тенью при `:hover` и подсветка всей карточки через `:focus-within` при навигации с клавиатуры.
8. **Улучшенная доступность формы (Accessibility)** — добавлены визуальные индикаторы обязательных полей (`*`), связка полей с подсказками через `aria-describedby`, атрибуты `aria-required="true"`, а также `role="status"` и `aria-live="polite"` для сообщения об успешной отправке.

## CSS-архитектура и БЭМ-структура проекта
В проекте используются:
- CSS-переменные в `:root` (цвета, шкала отступов, скругления, ширина контейнера);
- состояния `:hover`, `:active`, `:focus-visible`, `:focus-within`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid="true"`;
- БЭМ-блоки: `site-header`, `site-nav`, `breadcrumbs`, `hero`, `products-grid`, `product-card`, `product-table`, `faq`, `catalog-layout`, `catalog-filters`, `order-dialog`, `order-form`, `button`, `back-to-top`, `site-footer`.
