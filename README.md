# Учебный frontend-проект «ShopProject»

## Описание
Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема проекта: многостраничный сайт интернет-магазина цифровых комплектов, UI-китов и обучающих материалов для веб-разработчиков.

## Структура проекта
- `index.html` — главная страница (hero-блок, преимущества, витрина популярных товаров с изображениями, блок FAQ, модальное окно заявки);
- `catalog.html` — расширенный каталог из 6 цифровых товаров с тематическими иллюстрациями, фильтрами и CSS Grid-сеткой;
- `product.html` — детальная страница товара («Стартовый шаблон ShopStarter UI») с двухколоночной раскладкой, мини-галереей изображений, выбором редакции и таблицей сравнения комплектаций;
- `order.html` — отдельная страница оформления заказа и заявки;
- `contacts.html` — контактная информация и переход к обратной связи;
- `css/style.css` — единый файл стилей (CSS-переменные в `:root`, Flexbox, CSS Grid, методология БЭМ, интерактивные состояния и адаптивность);
- `js/main.js` — скрипт открытия/закрытия модального окна, подстановки выбранного товара и клиентской валидации формы;
- `images/` — директория для графических материалов проекта;
- `README.md` — документация проекта;
- `.gitignore` — список служебных файлов, исключённых из системы контроля версий Git.

## Ассортимент магазина (реализованные товары)
Вместо абстрактных заглушек в каталоге и на главной странице представлены конкретные цифровые продукты:
1. **Стартовый шаблон «ShopStarter UI»** (Арт. `SP-01`) — комплект из 5 адаптивных страниц интернет-магазина;
2. **Дизайн-система «RootTokens CSS»** (Арт. `SP-02`) — набор дизайн-токенов, палитр и CSS-переменных;
3. **Пакет форм «SmartForms & Dialog»** (Арт. `SP-03`) — коллекция доступных веб-форм и модальных окон `<dialog>`;
4. **Практикум «Мастер сеток: Grid & Flex»** (Арт. `SP-04`) — интерактивный курс и макеты по адаптивным сеткам;
5. **Руководство «БЭМ и доступность (a11y)»** (Арт. `SP-05`) — практическое пособие и чек-лист по архитектуре интерфейса;
6. **Полный бандл «Frontend-разработчик»** (Арт. `SP-06`) — максимальный комплект шаблонов, исходников и инструкций по деплою.

## Используемые технологии
- **HTML5** (семантическая разметка, веб-формы, таблицы, нативные элементы `<dialog>`, `<details>`/`<summary>`, оптимизированные изображения `<img>` с атрибутами `alt`, `width`, `height`, `loading="lazy"`);
- **CSS3** (дизайн-токены в `:root`, Flexbox, CSS Grid, кадрирование изображений через `object-fit: cover`, позиционирование `relative`/`absolute`/`sticky`/`fixed`, медиазапросы `@media`);
- **Методология БЭМ** (именование классов по схеме Блок — Элемент — Модификатор);
- **JavaScript** (управление модальным окном `<dialog>`, передача названия товара через `data-product`, клиентская проверка валидности);
- **Git и GitHub** (контроль версий, публикация статического сайта через GitHub Pages).

## Самостоятельные доработки
В рамках самостоятельного развития проекта и по результатам ревью реализованы следующие улучшения:
1. **Конкретные наименования и тематические изображения товаров** — все карточки на главной странице (`index.html`) и в каталоге (`catalog.html`) наполнены реальными названиями цифровых товаров, описаниями и иллюстрациями с фиксированными пропорциями (`object-fit: cover`) и отложенной загрузкой (`loading="lazy"`).
2. **Расширенный каталог товаров (`catalog.html`)** — сетка включает 6 карточек товаров с артикулами, рейтингом и абсолютно позиционированными бейджами (`position: absolute` внутри `position: relative`: «Хит», «Скидка -20%», «Новинка», «Топ»).
3. **Детальная карточка товара (`product-card--detailed` на `product.html`)** — разработана расширенная двухколоночная карточка товара:
   - блок галереи (`.product-card__gallery`) с главным изображением, сеткой из 3 превью-миниатюр (`.product-card__thumbs`) и тегами технологий (`.product-card__tags`);
   - подробный блок контента (`.product-card__content`) с артикулом, рейтингом, составом поставки (`.product-card__features`) и сводной панелью технических параметров релиза (`.product-card__specs-box`);
   - интерактивный блок выбора редакции лицензии Base / Pro на радиокнопках (`.product-card__options`) и блок покупки со старой перечёркнутой ценой (`.product-card__old-price`).
4. **Расширенная таблица характеристик и сравнения тарифов (`product.html`)** — создана семантическая таблица `.product-table` (`caption`, `thead`, `tbody`, `th`, `td`), сравнивающая базовую (Base) и расширенную (Pro) комплектации по 8 ключевым параметрам.
5. **Блок часто задаваемых вопросов (`index.html`)** — разработан интерактивный БЭМ-блок `.faq` на базе раскрывающихся семантических тегов `<details>` и `<summary>`.
6. **Улучшенное модальное окно (`index.html`)** — в блок `.order-dialog` добавлена выделенная шапка `.order-dialog__header` с заголовком, поясняющим подзаголовком `.order-dialog__subtitle` и разделительной линией.
7. **Фиксированная кнопка «Наверх» (`.back-to-top`)** — на всех страницах добавлена кнопка быстрого возврата к началу страницы с `position: fixed` и `z-index: 90`.
8. **Дополнительные состояния кнопок и карточек** — реализованы плавные переходы `transition`, масштабирование миниатюр галереи при наведении, состояние нажатия `:active` для кнопок, подъём карточек с тенью при `:hover` и подсветка карточки через `:focus-within` при навигации с клавиатуры.
9. **Улучшенная доступность формы (Accessibility)** — добавлены визуальные индикаторы обязательных полей (`*`), связка полей с подсказками через `aria-describedby`, атрибуты `aria-required="true"`, а также `role="status"` и `aria-live="polite"` для сообщения об успешной отправке.

## CSS-архитектура и БЭМ-структура проекта
В проекте используются:
- CSS-переменные в `:root` (цвета, шкала отступов, скругления, ширина контейнера);
- состояния `:hover`, `:active`, `:focus-visible`, `:focus-within`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid="true"`;
- БЭМ-блоки и модификаторы: `site-header`, `site-nav`, `breadcrumbs`, `hero`, `products-grid`, `product-card` (модификаторы `--featured`, `--discount`, `--detailed`, элементы `__gallery`, `__thumbs`, `__tags`, `__specs-box`, `__options`, `__purchase`), `product-table`, `faq`, `catalog-layout`, `catalog-filters`, `order-dialog`, `order-form`, `button`, `back-to-top`, `site-footer`.

## Как проверить проект
1. Открыть опубликованную версию на GitHub Pages: https://Andrey-Markovsky.github.io/kr1-html-css-shop/
2. Проверить переходы между всеми 5 страницами (`index.html`, `catalog.html`, `product.html`, `order.html`, `contacts.html`) и работу кнопки «Наверх».
3. Проверить отображение конкретных товаров и иллюстраций на главной странице и в каталоге.
4. Перейти на страницу «Товар» (`product.html`) и проверить расширенную карточку товара (галерею с миниатюрами, теги, блок спецификаций, переключатель версий Base/Pro) и сравнительную таблицу характеристик.
5. Проверить открытие модального окна по кнопке «Заказать», доступность полей и валидацию формы заявки.
